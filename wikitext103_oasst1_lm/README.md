## Datasets

This project uses the following publicly available datasets:

### WikiText
- **Source:** [Salesforce/wikitext](https://huggingface.co/datasets/Salesforce/wikitext)  
- **Description:** A language modeling dataset extracted from high-quality Wikipedia articles. Useful for training and evaluating language models on long-range dependencies.  
- **License:** CC BY-SA

### OpenAssistant Conversations (OASST1)
- **Source:** [OpenAssistant/oasst1](https://huggingface.co/datasets/OpenAssistant/oasst1)  
- **Description:** A human-generated conversational dataset with assistant-style dialogues and quality annotations. Commonly used for instruction tuning and alignment research.  
- **License:** Apache 2.0
